# EOS v0.19.0

Release Date: 2026-07-03

Release Name: EOS Alpha 0.19.0 - AI Workforce Operations

## Included Capability

- EOS-CAP-0027: AI Workforce Operations & Platform Administration Center

## Summary

This release adds the first integrated Digital Enterprise Headquarters operating layer for platform administration, governed admin actions, agent communications, agent activity, attention queue, local agent calendar, persistent navigation, and CEO headline metrics.

## Safety Notes

Governed platform actions remain display-only. Execution is disabled until permissions, persistence, audit controls, restore validation, and rollback controls are implemented.

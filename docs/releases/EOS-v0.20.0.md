# EOS v0.20.0

Release Date: 2026-07-03

Release Name: EOS Alpha 0.20.0 - Digital Headquarters Navigation

## Capability Included

- EOS-CAP-0028: Mission Control Navigation & Frontend Experience Redesign

## Summary

EOS v0.20.0 upgrades Mission Control into a workspace-based Digital Enterprise Headquarters experience. The release adds an Executive Command Bar, Digital Headquarters Lobby, Primary Workspace Rail, context navigation, breadcrumbs, and command palette foundation while preserving existing views and APIs.

- `EOS-WF-MISSION-CONTROL-EXPERIENCE-GOVERNANCE`

## Known Limitations

- Command palette execution is disabled until governed write APIs and audit controls exist.
- Visual regression tests are not yet automated.
- My Workspace routes are foundations and do not yet store user-specific tasks, decisions, or notes.

# EOS Kernel Registry

The Kernel Registry is the canonical inventory of every subsystem that forms the EOS Kernel.

Every Kernel component must be registered before implementation.

| KRN-006 | Ethics | Planned | Defines ethical governance | EOS CTO Office |

| KRN-011 | Build | Planned | Governs how EOS is constructed | EOS CTO Office |
| KRN-012 | Agent Contracts | Planned | Defines deployable agent contracts | EOS CTO Office |

## Rule

Nothing becomes part of the EOS Kernel unless it is first registered here.

# EOS Enhancement Index

The Enhancement Repository is the intake and governance layer for future EOS improvements.

Every meaningful idea that could improve EOS should become a structured Enhancement Object.

## Repository Structure

- inbox/ — new enhancement candidates
- planned/ — accepted but not yet active
- active/ — currently being developed
- completed/ — implemented and validated
- rejected/ — declined or deferred
- templates/ — reusable enhancement templates

## Operating Rule

Every meaningful EOS improvement idea must be captured as an Enhancement Object before it can be assigned, built, tested, approved, or deployed.

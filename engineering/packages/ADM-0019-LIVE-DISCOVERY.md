# ADM-0019 — Live Enterprise Discovery

## Objective

Implement the first complete Enterprise Journey.

## User Flow

Enterprise Control

↓

User enters:

https://company.com

↓

User presses:

Discover Enterprise

↓

EOS performs:

1. Website Discovery
2. Digital Intelligence Profile generation
3. Enterprise Intelligence Score
4. Opportunity Assessment
5. AI Workforce Recommendation
6. Digital Twin initialization
7. Second Balance Sheet Signal

↓

Enterprise Control updates live.

## Frontend

Replace the current fixed runtime with live runtime returned by:

POST /api/enterprise-discovery

## UI

Enterprise Control should include:

- Enterprise URL input
- Discover Enterprise button
- Discovery progress animation
- Runtime status
- Enterprise Intelligence cards

## Acceptance Criteria

✓ User can enter a website.

✓ Discovery executes.

✓ Runtime updates.

✓ Enterprise Control refreshes.

✓ Mission Control can open using discovered runtime.

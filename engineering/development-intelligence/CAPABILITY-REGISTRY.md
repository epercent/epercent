# EOS Capability Registry

Every major capability in EOS must be tracked as a governed capability.

For each capability record:

- Capability ID
- Name
- Description
- Owner Office
- Assigned Engineering Office
- Status
- Completion %
- Demo Ready
- Commercial Ready
- Dependencies
- Current Mission
- Last Commit
- Acceptance Criteria
- Technical Debt
- Next Recommended Action

This registry is the authoritative source for measuring EOS development progress.

Future versions of EOS will maintain this registry automatically and expose it through Enterprise Control.
